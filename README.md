# 坦克动荡前端

采用 Nuxt 框架，TypeScript，使用 Tailwindcss、Pinia、Canvas2D

### 基本信息

还原原版坦克动荡，俯视 2D 迷宫坦克对战，炮弹碰到墙壁会反弹，可以利用墙壁折射子弹击杀敌人，也很容易打死自己，在迷宫地图里操控坦克，发射炮弹击毁敌方坦克；击毁对手得 1 分，自己被炸掉对手得分。一局只剩最后一个玩家或全部死亡后立刻换一张新迷宫，积分累计

加入简易的账号系统实现联机，输入玩家 ID 进行邀请加入房间，当房间中所有玩家点击**开始**按钮时开始游戏，**所有物理计算在后端进行**

### 操作

坦克会自动朝向鼠标指针的位置，W 前进 S 后退，左键开火

### 技能/道具

1. 激光：会有一条瞄准射线虚线，激光的速度比子弹更快
2. 碎片炸弹：发射一枚更大的炮弹后再按一次攻击或过一段时间后会分裂成数量庞大的三角形小碎片
3. WIFI弹：发射一枚可以变向的导弹，由玩家进行瞄准，期间坦克不可移动
4. 加特林：长按攻击键可以发射，发射时可移动
5. 追踪导弹：给你一枚坦克追踪导弹。大约 2 秒后，它会寻找最近的坦克。甚至可能追随开枪者！如果有坦克靠近，它有时还会切换目标
6. 陷阱：给你 3 个地雷，可放置，放置后隐形，松发式，爆炸时生成数量庞大的三角形小碎片

## 安装

```bash
pnpm install
```

## 测试服务器

将会在 `http://localhost:3000` 上启动测试服务器:

```bash
pnpm dev
```

## 构建

构建产物:

```bash
pnpm build
```

在本地预览生产构建产物:

```bash
pnpm preview
```
